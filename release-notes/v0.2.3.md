# v0.2.3 — Second Audit Pass: Documentation, DRY, and Residual Bugs

## Summary

A follow-on audit pass fixing two real bugs uncovered after v0.2.2, removing
residual dead code, and bringing every public API item up to documentation
standard.

## Bug Fixes

### `encode_video()` panicked on empty input instead of returning an error

`encode_video()` called `is_keyframe(data)` before `write_video()`'s
empty-data guard. The `assert_invariant!(!data.is_empty())` inside
`is_keyframe()` would fire — panicking — before `write_video()` had a
chance to return `MuxerError::EmptyVideoFrame`. An early guard is now
added at the top of `encode_video()` so `is_keyframe()` is never reached
with empty data.

### `MuxStats.duration_ms` was always 0 in CLI JSON output

The field was initialized to 0 and never updated. The CLI now calls
`muxer.finish_with_stats()` and derives `duration_ms` from
`MuxerStats::duration_secs`.

## Dead Code Removed

- Redundant `let _ = sample_count;` in `SampleTables::from_samples`
  (`sample_count` was already used for `Vec::with_capacity`).
- Unused top-level `use crate::assert_invariant` in `api.rs`.

## Documentation

All public API items in `api.rs` now have complete doc comments:

- `MuxerBuilder` struct doc updated (removed stale "future slices" language).
- `build()` comment de-versioned.
- `finish_in_place()` doc no longer references internal test names.
- `finish()` and `finish_with_stats()` documented.
- `write_audio()` now mentions both AAC and Opus.
- `encode_video()` and `encode_audio()` expanded with usage guidance.
- `MuxerConfig` and `MuxerStats` — all fields documented.
- `Metadata::new/with_title/with_creation_time` — docs added.
- `MuxerConfig::new/with_audio/with_metadata/with_fast_start` — docs added.

## Code Organisation

- `simple_api_works` test + `make_h264_keyframe` helper moved from
  `thread_safety_tests` to the `tests` module.
- `test_poisoned_lock_paths_are_handled` in `invariant_ppt.rs` renamed
  to `test_invariant_log_records_and_clears`; stale comment removed.

## Refactor

- Magic literal `3000` (90 kHz ticks for 1 frame @ 30 fps) in
  `fragmented.rs` replaced with `FALLBACK_FRAME_DURATION_TICKS`.
- Duplicate DTS-span calculation in `FragmentedMuxer` extracted to
  private `buffered_duration_ms()`; `ready_to_flush()` and
  `current_fragment_duration_ms()` both delegate to it.

# v0.2.4 — Test Rename, Benchmark Repair, Doc Consistency

## Summary

A maintenance release with no API or behavior changes. Fixes the Windows
integration-test failure caused by elevation heuristics, repairs the benchmark
harness to use valid fixture data, and brings contract and README documentation
in sync with the actual implementation.

## What Changed

### Bug Fix — Windows test failure
`tests/video_setup.rs` was renamed to `tests/video_track_structure.rs`.
Windows treats any executable whose name contains "setup" as a potential
installer and requests UAC elevation (OS error 740). The test binary produced
for that integration test was named `video_setup.exe`, which triggered this
heuristic on every Windows run. The rename eliminates the false positive.

### Benchmark Fix
Both benchmarks in `benches/muxing.rs` previously wrote 10 KB zero-byte
buffers as "frames". Zero-byte input fails H.264 validation and is never
written — the benchmarks were measuring essentially nothing. They now use the
same hex-encoded fixtures used by the integration tests (`frame0_key.264`,
`frame1_p.264`, `frame0.aac.adts`) and complete successfully.

### Documentation
- `docs/contract.md`: keyframe invariant now specifies required headers for
  each codec; pseudo-code example corrected to `Aac(AacProfile::Lc)`.
- `README.md`: removed an unsupported benchmark table (numbers were
  environment-specific and measured on development hardware); replaced with a
  pointer to `cargo bench`. Fixed a stray `</details>` tag.
- `ROADMAP.md`: Recent Achievements entries now describe changes rather than
  calling out internal process.
- `release-notes/v0.2.1.md`, `release-notes/v0.2.2.md`: added previously
  missing release-note files.

## Compatibility

No API changes. No behavior changes. Drop-in replacement for v0.2.3.
